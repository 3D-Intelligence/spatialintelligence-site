# Spatial Intellingence

Spatial Intelligence is a deeptech AI startup building tools for machines that understand the structure and content of 3D environments - unlocking new frontiers across gaming, architecture, and robotics.

## Spintel

(Product)

Spintel is a product suite by Spatial Intelligence for generating production-ready 3D environments from natural language descriptions.

## Spatial Context Protocol (SCP)

(Applied AI Research)

Spatial Context Protocol is an open protocol for AI agents to understand the physical world — enabling LLMs to navigate buildings, identify locations, and control their environment in real time.

## Object Representation Learning

(Fundamental AI Research)

CORD (Compositional Object Representation via Detection transformers), is a research programme for learning structured, holistic object representations from object detection. Learned object representations capture distinct components of object understanding: what it is (semantic), where it is (spatial), what it canonically looks like (class prototype), and how it relates to everything else in the scene (relational), producing object query representations substantially richer than those obtainable through detection training alone.
