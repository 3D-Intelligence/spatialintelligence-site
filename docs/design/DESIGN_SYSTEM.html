Design System · v2.1

SCP Design System

The shared visual language behind the Spatial Context Protocol surfaces. Use the toggle in the top-right to flip between the paper-warm light surface and the cool, gridded dark surface — every component below switches in lockstep with the live SCP page.

01 · Themes Two surfaces, one system

Light & Dark, paired by intent

SCP ships in two paired surfaces driven by a single set of CSS custom properties — flipped via [data-mode="dark"] on the html element. Toggling the sun/moon control above swaps every token, and components re-skin themselves accordingly. The hero uses DM Sans 300 in light, Syne 300 in dark; the rest of the type system is shared.

When to use which

04 · Spacing 8px base

Spacing & rule

8px base unit. Sections are tall — 80–96px vertical padding sets the publication-document rhythm. Rules are 1px hairlines in --rule; never thicker except for the 2–3px teal accents on key callouts.

Vertical scale

12caption gap · figure → figcaption
16paired figures · component padding
24paragraph spacing · within terminal
32terminal padding · between subsections
48container side padding · figure margin
64overview-grid gap · between examples
80section vertical padding (default)
96hero / closing vertical padding

Border-radius — none

SCP uses zero border-radius. All edges are square in both modes. The exceptions are the three terminal traffic-light dots and any inline status pulses.

11 · Callouts Insight + key principle

Callouts

Two callout flavours. Insight closes each example. Key principle sits in the overview grid as a pinned aside. Both re-skin on toggle: light leans on a teal left-border; dark wraps the content in a raised box with a teal top-border.

Insight — closes each example

Insightlight: 2px top · dark: 1px top

The agent traverses the building as a human would, identifies the two-hop route, and produces turn-by-turn directions with named landmarks. Real-time traversal of the underlying spatial model underpins the system and enables deployment across multiple venues.

Key principle — overview aside

Key principlelight: left rule · dark: top rule

Key principle

The spatial model is the only thing that changes between buildings. Author a model for a new location and the same agent is immediately deployable there.

13 · Step grid Three-column process

Step grid

Three equal columns describing a process — never more, never fewer. Light mode: open layout with 40px gap, body in DM Sans. Dark mode: bordered cells with hairline dividers, body in JetBrains Mono.

Step gridre-skins on toggle

Simple inputs

02

Compact model

Human-readable spatial model encoding rooms, routes, landmarks, and live state.

03

Deploy anywhere

Same agent, any building. Swap the spatial model — no bespoke engineering.

14 · Voice Plain, technical, quiet

Voice & copy

SCP writes like a research note, not a marketing page. Plain technical English. No exclamations. No second-person sales address. Specific numbers ("13.9 m") over vague claims. Verbs lead. Voice does not change between modes.

Tone principles

  • Specific over vague Cite measurements, room counts, procedures. Avoid "powerful", "intelligent", "next-gen".
  • Third-person system "The agent traverses the building" — not "we let you talk to your building". The reader is observing, not being sold to.
  • Em-dashes, not bullets Prose flows in paragraphs with the occasional em-dash aside. Bulleted lists are reserved for step grids and tables.
  • No CTAs No "Get started", no "Talk to sales". The page closes with a statement of intent, not an action.

Do / don't

Do
"Total distance: approximately 13.9 m."
Don't
"Get there fast — your AI knows the way!"
Do
"The agent has no pre-computed routes."
Don't
"Lightning-fast real-time navigation magic."
Do
"A protocol for AI agents that understand the physical world."
Don't
"Revolutionize your building with the future of AI."

"Spatial Context Protocol" uses display weight 300 with the second word coloured teal. Light mode keeps it italic (DM Sans); dark mode is upright (Syne). Never re-color the body word; never set the accent word in any color but teal.
