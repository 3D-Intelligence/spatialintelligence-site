## Problem

The Spintel pillar on `index.html` currently shows a static `top_down.png` image.
Replacing it with an interactive Three.js GLB viewer would let visitors orbit, pan, and
zoom around an actual Spintel scene generation — a more compelling demonstration of the
product than a flat image.

## Fix

### 1. Prepare the GLB asset

Place the DRACO-compressed GLB for scene_208 at `assets/models/scene-208.glb`.
Aim for <10 MB. If the raw export exceeds this, compress with `gltf-pipeline -i scene_208.glb -o scene-208.glb --draco.compressionLevel 10`.

Do not commit a file over 100 MB (git hard limit).

### 2. Add the import map to `index.html`

Insert the following immediately before the existing `<script type="module" src="js/main.js">` tag at the bottom of `<body>`. An import map must appear before any module scripts that use it.

```html
<script type="importmap">
{
  "imports": {
    "three": "https://cdn.jsdelivr.net/npm/three@0.169.0/build/three.module.js",
    "three/addons/": "https://cdn.jsdelivr.net/npm/three@0.169.0/examples/jsm/"
  }
}
</script>
```

### 3. Replace the figure markup in `index.html`

In the Spintel pillar, replace the existing `<figure class="figure">` block (which
contains `top_down.png`) and its `<p class="figure-cap">` with:

```html
<figure class="figure figure--viewer">
  <div class="figure-img-wrap">
    <canvas id="spintel-viewer" aria-label="Interactive 3D scene generated by Spintel"></canvas>
    <p class="viewer-hint">Drag to orbit · Scroll to zoom</p>
  </div>
  <div class="figure-bar">
    <span>Fig. 1 · scene_208</span>
    <span class="figure-bar-tag">Spintel · text → scene</span>
  </div>
</figure>
<p class="figure-cap">A 13-room multi-functional building, fully furnished from a single text prompt. Floors, walls, fixtures, and props all generated by the Spintel pipeline.</p>
```

### 4. Create `js/viewer.js`

Vanilla JS ES module. Initialises a Three.js viewer on `#spintel-viewer` and loads
`assets/models/scene-208.glb` automatically on page load.

```js
import * as THREE from 'three';
import { OrbitControls } from 'three/addons/controls/OrbitControls.js';
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';
import { DRACOLoader } from 'three/addons/loaders/DRACOLoader.js';
```

DRACO decoder path (CDN): `https://www.gstatic.com/draco/versioned/decoders/1.5.6/`

Viewer behaviour:
- WebGL renderer, SRGB colour space, ACESFilmic tone mapping
- Perspective camera, FOV 45°, auto-rotate on load, stops on first user interaction
- OrbitControls with damping enabled
- Ambient light + two directional lights (key and fill)
- On load: fit camera to bounding box, centre model at origin
- Show `loading…` overlay text on the canvas while GLB is fetching; hide on load
- Resize observer on the canvas container — renderer and camera aspect update on resize
- Guard the canvas selector with a null check; if `#spintel-viewer` is absent, return early

Add `<script type="module" src="js/viewer.js"></script>` after the import map in `index.html`.

### 5. Add viewer styles to `css/styles.css`

Append a `/* ── Viewer ── */` section to `css/styles.css`:

- `.figure--viewer canvas` — `width: 100%; aspect-ratio: 16/9; display: block;`
- `.viewer-hint` — small mono caption, muted colour, centred, fades out after first pointer interaction (add/remove a `.interacted` class via JS)
- No new hard-coded colour values — use existing CSS custom properties
